# Internationalization

Agent Tick uses Lingui with English source strings and PO catalogs.

## How to add UI copy

- Write the English text where the UI uses it.
- Mobile/React Native can use Lingui macros over time, or the shared `i18n._(...)` helper for simple strings.
- Admin/Svelte currently uses the small `tr('English text')` helper in `apps/admin/src/App.svelte`.
- If Svelte text is translated through `tr(...)`, add the same string to `apps/admin/src/adminI18nMessages.ts` so Lingui can extract it until we add a reliable Svelte extractor.

## Translation workflow

After changing translatable copy, run:

```sh
corepack pnpm i18n:extract
corepack pnpm i18n:compile
```

Catalogs live in:

```txt
packages/i18n/src/locales/en/messages.po
packages/i18n/src/locales/da/messages.po
```

Compiled runtime catalogs are generated beside them as `messages.ts` files and should be committed.

## Checks

Use this before finishing i18n changes:

```sh
corepack pnpm i18n:check
corepack pnpm typecheck
corepack pnpm --filter agent-tick-admin check
```

`i18n:check` extracts catalogs, compiles them, and runs a strict visible-string audit. The audit fails when mobile/admin source contains visible English UI copy that is not captured in the Lingui source catalog. To intentionally add new visible copy, run:

```sh
corepack pnpm i18n:audit:update
corepack pnpm i18n:extract
corepack pnpm i18n:compile
```

Then translate the new PO entries.

## Locale behavior

Both apps support a `System` preference. System uses the device/browser locale when it matches a supported language, otherwise it falls back to English. Users can also select a concrete language from the in-app language selector.
