Market categories

The market clusters into four groups. Agent Tick is strongest as a focused, self-hostable approval gate, while competitors often win on setup, MCP reach, no-code workflow distribution, or SDK ergonomics.

Dedicated approval infrastructure

HumanLayer, gotoHuman, Queuelo, Approve AI, AwaitHuman, HumanAssist, OKrunit, HITL Relay, HumanRail, HumanOps, HumanLatch, CodeVF, Arahi.

MCP / agent governance gateways

Preloop, Permit MCP Gateway, Airlock, call-a-human MCP, and lightweight open-source MCP human-in-the-loop servers.

Workflow automation platforms

Zapier, n8n, Relay.app, EnforcedFlow, and approval gateways that live where business users already configure automations.

Framework/runtime primitives

LangGraph interrupts, Cloudflare Agents `waitForApproval`, FastMCP Approval, PromptRails, and useworkflow hooks.

Pricing observations

Free tiers are table stakes

Queuelo, Approve AI, OKrunit, HITL Relay, and HumanAssist publish free/hobby tiers with 50–1,000 requests/interactions.

Low-end paid cluster

Individual/pro tiers often land near $15–20/mo: Queuelo $19, OKrunit $20, HITL Relay $14.99.

Team plans cluster higher

Entry team plans commonly land around $49–99/mo: Queuelo Team $49, gotoHuman Team $99, Approve AI Pro $99.

Enterprise is custom

Governance/gateway platforms such as Preloop, Permit, HumanLayer, and OKrunit reserve RBAC, SSO, retention, and deployment controls for custom enterprise tiers.

Meta report: what Agent Tick should copy

Highest priority

One-command agent discovery and setup

Add `agent-tick discover` and guarded `agent-tick integrate <target>` flows for Claude Code, Cursor, Codex CLI, Gemini CLI, Windsurf, OpenCode, MCP configs, GitHub Actions, and repo scripts.

Highest priority

MCP server integration

Implement a narrow MCP tool surface: `request_approval`, `ask_human`, and `notify_human`, with copy-paste config snippets for popular clients.

Highest priority

SDK ergonomics: `await tick.approve()`

Add TypeScript/Python helpers and framework examples for LangGraph, LangChain, CrewAI, Vercel AI SDK, and OpenAI tool calling.

Highest priority

No-code workflow connectors

Build an n8n community node first, then Zapier/Make actions. Include deploy, refund, outbound email, migration, and payment approval recipes.

Highest priority

Approval templates and richer review forms

Support typed templates with required fields, custom choices, risk labels, links, attachments, and reviewer guidance.

Highest priority

Secure expiring guest approval links

Offer scoped one-use or short-lived links for reviewers who should not need a full dashboard account, while preserving authenticated org approvals by default.

Highest priority

Notification channel expansion

Add first-class Slack and Teams, then consider Discord/Telegram. Keep the existing generic webhook sink for custom integrations.

Medium

Passkey-backed high-assurance approvals

Useful for payment, procurement, production, and legal workflows. Produce signed approval receipts without becoming an e-signature platform.

Medium

Policy explanation and risk scoring

Show matched policy, risk score, why approval is required, and audit evidence to help reviewers decide faster.

Medium

Batch approval mode

Let reviewers quickly approve/reject repetitive queue items, inspired by EnforcedFlow and approval queue products.

Medium

E2EE or payload redaction mode

Allow agents to send sensitive fields encrypted or redacted in notifications, with full detail only in dashboard/mobile.

Medium

Usage and billing transparency

Publish usage endpoints and clear plan limits if/when hosted pricing is formalized. OKrunit is a useful model.

Avoid for now

External human worker marketplace

HumanRail/HumanOps/CodeVF are different businesses with marketplace, quality, labor, and compliance complexity.

Avoid for now

Full model gateway / spend control

Powerful, but too broad for the next slice. Integrate with gateways later; focus now on approval setup and review UX.

Avoid for now

Broad no-code AI employee platform

Arahi-style platforms are too broad. Agent Tick should be the approval layer they call.

Suggested roadmap slices

  1. MCP MVP: `agent-tick mcp` or a separate package, tools for approval/wait/ask, and mocked MCP integration tests.
  2. n8n node: create request, wait/poll for decision, branch on approve/reject, with self-hosted server URL/token config.
  3. Agent discovery CLI: read-only `agent-tick discover`, then guarded write mode later.
  4. Templates: server schema, dashboard editor, CLI/SDK `--template` support.
  5. Slack/Teams notifications: minimal notifications with dashboard links; avoid bearer tokens in URLs.
