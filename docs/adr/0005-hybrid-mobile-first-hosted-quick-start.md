# Hosted Quick Start is hybrid mobile-first

The hosted onboarding flow introduces Native App install/sign-in first, proves phone delivery with a first-party safe Steering Test Request that does not require an Agent Connection, then uses the setup skill/CLI path to connect an Agent Connection. This replaces the earlier CLI/web-proof-first sequence because the Native App is the primary day-to-day approval surface, while keeping CLI instructions visible from the start and avoiding trial pressure before demonstrated value.
