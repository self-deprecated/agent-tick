# Test Requests bypass Native App trial requirements

Setup Test Requests can be answered in the Native App before or outside an active personal Trial so users can prove mobile routing and see value before paywall pressure. Non-test Requests still require the appropriate Trial, Personal Hosted Subscription, App Purchase, or paid Shared Workspace entitlement before the Native App can submit a response, and Trial-bypassing Test Requests are created only by first-party setup/test controls in the web app/server so arbitrary Agent Connections cannot mark production Requests as free tests.
