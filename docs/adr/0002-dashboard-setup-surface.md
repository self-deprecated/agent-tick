# Dashboard setup surface

The hosted web app defaults to a focused Dashboard for the common Solo Developer setup path instead of presenting a broad administration surface or marketing landing page.

Setup, Agent Connection status, and safe test routing are primary. Activity History and Settings are secondary surfaces. Organization, billing, and Team Routing administration stay hidden until the active account, membership, or entitlement supports them.

This trades immediate visibility of every administrative capability for a simpler functional setup surface that matches the product's most common first-run workflow: connect a local agent, prove a bounded Request, then add the Native App or shared Organization features when needed.
