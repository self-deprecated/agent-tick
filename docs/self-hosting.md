# Self-Hosting

Service self-hosting is free under the source-available BSL license. Internal commercial self-hosting is allowed. Offering Agent Tick as a hosted or managed service to third parties is prohibited during the BSL period.

The BSL conversion date is 2028-05-31.

Self-hosting the service does not include permanent first-party Native App use. The Native App has a 7-day Trial; after that, the first-party app is paid via Lifetime app unlock. Self-hosted deployments use polling/manual refresh in the first-party app by default at launch, unless the self-hoster configures their own notification hooks/webhooks/notifiers.

Detailed environment variables and deployment examples should stay in this docs site as the self-hosting surface expands. For now, use the CLI installer and server configuration examples in this repository as the launch baseline.
