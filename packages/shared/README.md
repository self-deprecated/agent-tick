# @self-deprecated/agent-tick-shared

Shared Zod schemas, API types, and constants for Agent Tick.

Most application and integration code should import `AgentTickClient` from `@self-deprecated/agent-tick-sdk`. Use this package when you need the lower-level schemas or shared helper types directly, including Agent Activity `sessionId`/Session metadata schemas and Status Update semantic-state helpers for `working`, `waiting`, `blocked`, `done`, and `failed`.

See <https://docs.agenttick.sh> for API and integration docs.
